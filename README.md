# 나의 플래너 (Todo / Daily Routine)

수첩 느낌의 To-do 앱. **데일리 루틴**과 **과제**를 분리해서 관리합니다.

- **오늘**: 그날의 루틴 체크리스트 + 마감 임박 과제(D-day)
- **루틴**: 요일별 반복 루틴 등록, 월간 트래커 표(칸을 눌러 체크)
- **과제**: 시작일/마감일, 과목, 메모, 세부 단계와 진행률
- **월간**: 달력에 과제 기간 바, 날짜별 루틴 달성률 표시

빌드 없이 `index.html`을 브라우저로 열면 됩니다. 데이터는 브라우저 `localStorage`에 저장됩니다.
